# AakPyChan
AkaPyChan 是我們團隊的大學專題作品，主題為**互動式 Python 初學者教學平台**。 

在這個專案中，我主要負責 前端開發，包含版面設計、網頁結構規劃與互動效果實作。
- 前端 UI/版面設計  
- 網頁結構與切版  
- 按鈕互動邏輯與教學頁面呈現  

## 專案環境設定
### 建立虛擬環境
```bash
python3 -m venv myenv
```
### 進入虛擬環境
```bash
source myenv/bin/activate
```
### 退出虛擬環境
```bash
deactivate
```
### 安裝相關套件
```bash
pip install -r requirements.txt
```
### 執行
```bash
cd backend
uvicorn main:app --reload
```
```bash
cd backend
npm install
npm run dev
```

### AI助教聊天室
AI 助教聊天室為全螢幕設計的對話介面，提供使用者一個專注、沉浸的提問環境。畫面以對話區為核心，搭配輸入列與常用指令按鈕，支援程式碼貼上、語法詢問、錯誤訊息解讀與題目解析等互動。
相較於嵌入在教材頁右側的助教欄位，獨立的聊天室頁面更適合進行「深度討論」與「連續對話」，例如請 AI 協助規劃學習路徑、重構程式或比較多種解法。

![AI助教聊天室](https://github.com/omm0102/AkaPyChan/blob/main/AI%E5%8A%A9%E6%95%99%E8%81%8A%E5%A4%A9%E5%AE%A4.png)
### 教材學習頁面
教材學習頁面為平台的主要知識呈現區，結合章節式教材與固定式 AI 助教輔導功能。整體畫面採三欄式版面：左側為單元選擇區，中間為教材內容區，右側為嵌入式助教聊天欄。使用者可透過左側選單切換主題，中間即時更新對應的教學內容（文字說明、程式範例、重點整理），並在閱讀過程中直接於右側向 AI 助教提問。
此頁面強調「學習不中斷」的設計理念，讓「看教材」與「問問題」在同一畫面中完成，減少視窗切換與情境中斷，形成「教材理解 → 即時輔導」的學習迴圈，符合使用者中心與降低認知負荷的設計原則。

![教材學習頁面](https://github.com/omm0102/AkaPyChan/blob/main/%E6%95%99%E6%9D%90%E5%AD%B8%E7%BF%92%E7%95%AB%E9%9D%A2.png)
### 程式練習頁面
程式練習頁面專注於題庫練習與實作驗證，模擬實際解題平台的操作情境。畫面同樣採多區塊設計：左側為題目選擇區，中間為使用 Monaco Editor 的程式編輯區，右側則顯示題目敘述與程式執行結果，並整合提示與解答功能。使用者在選定題目後，可直接於中間區撰寫 Python 程式，按下 RUN 後即時看到輸出與驗證結果。當使用者在解題過程中需要協助時，可依序使用「提示」、「顯示解答」或點擊開啟 AI 助教聊天室進行更深入的說明。此頁面對應「教材理解 → 練習驗證」的階段，強調獨立思考與除錯能力的培養，同時保留 AI 輔助作為支援機制，形成完整的自學循環。
